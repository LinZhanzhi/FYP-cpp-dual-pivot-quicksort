## Assessment Criteria

### 1. Background and Related Work (5%) — PILO 6

| Grade | Description |
|-------|-------------|
| **A+/A/A-** | Excellent background, comprehensive references with complete review and in-depth analysis |
| **B+/B/B-** | Clear background with most relevant references and good overview and analysis |
| **C+/C/C-** | Basic relevant background with sufficient references and basic overview |
| **D+/D** | Barely relevant background and minimal references with brief review and obvious deficiencies |
| **F** | Irrelevant background with insufficient references and many errors and omissions |

---

### 2. Problem Definition and Objectives (5%)

| Grade | Description |
|-------|-------------|
| **A+/A/A-** | Very well-defined and motivated problem(s) with clear and attainable objective(s) |
| **B+/B/B-** | Clear problem(s) and objective(s) with suitable scope |
| **C+/C/C-** | Acceptable problem(s) and objective(s) with suitable scope but room for improvement |
| **D+/D** | Unclear problem(s) and objective(s) with obvious deficiencies (e.g., unclear scope) |
| **F** | Unacceptable problem(s) and objective(s) with many deficiencies |

---

### 3. Design/Methodology and Critical Thinking (15%) — PILO 4

| Grade | Description |
|-------|-------------|
| **A+/A/A-** | Thorough design/methodology, academically rigorous and excellent critical thinking (e.g., considering different alternatives) |
| **B+/B/B-** | Good design/methodology and good critical thinking with minor deficiencies |
| **C+/C/C-** | Basic design/methodology and basic critical thinking with room for improvement |
| **D+/D** | Weak design/methodology and weak critical thinking with obvious deficiencies |
| **F** | Poor design/methodology and lack of critical thinking with many deficiencies |

---

### 4. Problem Solving, Implementation and Evaluation (45%) — PILO 5

| Grade | Description |
|-------|-------------|
| **A+/A/A-** | Problem solved optimally and in a comprehensive manner (e.g., innovative or complex approach) with complete implementation and evaluation |
| **B+/B/B-** | Problem solved by good techniques (e.g., overcoming difficult problems) with almost complete implementation and evaluation |
| **C+/C/C-** | Problem solved with basic/standard technique (e.g., overcoming standard problems) with basic implementation and evaluation |
| **D+/D** | Problem barely solved with obvious deficiencies, and little implementation and evaluation |
| **F** | Very little problem solving, implementation and evaluation with many deficiencies |

---

### 5. Report Writing (10%) — PILO 1

| Grade | Description |
|-------|-------------|
| **A+/A/A-** | Very well-written and well-structured with fluent English, and very clear discussion and explanation |
| **B+/B/B-** | Well-written and well-structured with clear discussion and explanation but minor deficiencies |
| **C+/C/C-** | Readable and structured but with room for improvement in some aspects |
| **D+/D** | Barely readable and structured with obvious deficiencies |
| **F** | Unreadable with many deficiencies |

---

### 6. Presentation (10%) — PILO 1

| Grade | Description |
|-------|-------------|
| **A+/A/A-** | Comprehensive and very clear logical presentation showing in-depth understanding. Excellent response to all questions |
| **B+/B/B-** | Good, easy to follow presentation showing good understanding with minor deficiencies. Good response to major questions |
| **C+/C/C-** | Basic presentation showing basic understanding with acceptable deficiencies. Major questions answered |
| **D+/D** | Weak presentation showing weak understanding with major deficiencies. Questions answered unsatisfactorily |
| **F** | Poor presentation showing little understanding. Poor response to questions. No presentation file |

---

### 7. Project Management and Meeting Notes (10%)

**Requirement**: At least 4 meeting notes between January and April

| Grade | Description |
|-------|-------------|
| **A+/A/A-** | Excellent project management with comprehensive meeting notes showing consistent progress and supervisor engagement |
| **B+/B/B-** | Good project management with complete meeting notes (≥4) showing regular progress |
| **C+/C/C-** | Adequate project management with sufficient meeting notes meeting minimum requirement |
| **D+/D** | Poor project management with insufficient meeting notes (<4) |
| **F** | No evidence of project management or meeting notes |

---

## Weight Summary

| Component | Weight |
|-----------|--------|
| Background and Related Work | 5% |
| Problem Definition and Objectives | 5% |
| Design/Methodology and Critical Thinking | 15% |
| Problem Solving, Implementation and Evaluation | **45%** |
| Report Writing | 10% |
| Presentation | 10% |
| Project Management and Meeting Notes | 10% |
| **Total** | **100%** |

## PILO Reference
- **PILO 1**: Communication skills (Report Writing, Presentation)
- **PILO 4**: Critical thinking and design methodology
- **PILO 5**: Problem solving and implementation
- **PILO 6**: Research and background investigation
